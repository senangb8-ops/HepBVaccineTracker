Quick guide: adding the .ics file to your calendar
  1. Google Calendar: On desktop, open Google Calendar → gear icon (Settings) → "Import & export" → Import → choose the downloaded .ics file → Import.
  2. iPhone / Apple Calendar: Open the downloaded .ics file (e.g. from Files or Mail) → tap it → "Add All" when prompted.
  3. Outlook: File → Open & Export → Import/Export → "Import an iCalendar (.ics) file" → select the file.
  4. Each dose imports as its own event with a 1-day-before reminder built in.
